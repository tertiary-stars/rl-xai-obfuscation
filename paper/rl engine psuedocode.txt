// ==========================================
// Initialization phase
// ==========================================
Initialize Target Model M
Initialize XAI Module to generate baseline explanations E_true(x)
Initialize RL Agent (Defender) with policy π
Define hyperparameters:
    λ     (security weight - swept in the experiments)
    μ     (distortion weight - fixed, e.g. 0.05)
    T_max (queries per episode / user session)
    k     (rolling-window length of the state)
    W     (number of recent queries the adversary error is averaged over, e.g. 32)

// ==========================================
// Main Adversarial Min-Max Game Loop
// ==========================================
For each episode (simulating a unique user/attacker session):

    // Reset state for the new session
    Draw a random session of queries x_1, ..., x_T_max
    Clear the query history; reset Adversary Surrogate Model S

    For time step t = 1 to T_max:

        // 1. Process Input Query
        Receive input query x_t from user
        Compute target model output: y_t = M(x_t)

        // 2. State formulation (Step 1 of paper) - fixed-size encoding of the history
        z_t = (x_t - mean_train) / std_train
        Rolling window:  s_t = [z_{t-k+1}, ..., z_{t-1}, z_t, t/T_max]

        // 3. True Explanation Generation
        Compute baseline true explanation: E_true = XAI(M, x_t)

        // 4. RL Agent Action & Obfuscation (Step 2 of paper)
        a_t = π(s_t),  a_t ∈ [0, 1]
        E_output = (1 - a_t) * E_true + a_t * ε,   ε ~ N(0, σ_E²)
        // a_t = 0: exact explanation;  a_t = 1: pure noise (full obfuscation)

        // 5. System Output Delivery
        Return y_t and E_output to the user/adversary

        // 6. Adversary Error (security score, Step 3 of paper)
        AdversaryError_t = cross-entropy of S against M's labels on the last W queries
        // S tries to make this LOW; the defender wants it HIGH.

        // 7. Explanation Distortion and Reward (Step 4 of paper)
        Distortion_t = ||E_true - E_output|| / ||E_true||
        R_t = λ * AdversaryError_t - μ * Distortion_t

        // 8. Adversary learns
        Update S on ([x_t, E_output], y_t)

        // 9. Agent Optimization
        Store (s_t, a_t, R_t, s_{t+1}); update π with PPO to maximise Σ R_t

    End For
End For

Return trained RL Agent Policy π
